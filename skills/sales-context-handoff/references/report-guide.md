# Short report format

Modified 2026-11-20 from zarif3624/gtm-context's context template.

Write for the recipient and purpose saved in progress, using the business name and clear factual descriptions. Include only supported, useful sections. Preserve exact outreach in extracts; reports can link to longer sequences.

| Recipient | Emphasis in the reports |
| --- | --- |
| New sales hire | Selected offers, buyer problems and roles, sales stages, current qualification practices, objections and documented conversation examples. Explain unfamiliar business terms from supplied material; flag missing onboarding context. |
| GTM engineer | Supported win/loss patterns, lightweight targeting/signal hypotheses, source coverage and missing inputs affecting architecture, data models and decision logic. Supply evidence for design; do not create an implementation specification. |
| Other | Use the saved role and needs to prioritize context, examples and open questions. Do not invent a role-specific playbook beyond the evidence. |

Keep the same evidence standards for every recipient. Qualify historical practices and seller explanations rather than presenting them as proven best practice. Changing the recipient changes emphasis, not recorded facts.

| File in working/reports | What to include |
|---|---|
| sales-context.md | Offer, costly customer problem, existing ICP/personas, sales motion, stages, qualification/scoring definitions, constraints and documented practices; distinguish current from historical material |
| findings.md | Sample/coverage, supported win/loss factors with counts and counterexamples, buying roles, one deal walkthrough, lightweight hypotheses |
| outreach-examples.md | Curated examples with channel, context, exact message excerpts, observed reply/meeting/won association and source links |
| gaps.md | Missing data, contradictions, inaccessible/unqueried sources and next inputs needed for the recipient's purpose; enrichment only where relevant |

The CSV tables are the deal evidence deliverable; do not duplicate every row in prose. If a report has no supporting evidence, say what was unavailable in one sentence rather than filling a template with unknowns.

Every material factual statement cites one or more evidence IDs, for example [ev-0001](../extracts/ev-0001.md). Keep working and handoff relative layouts identical. Inferred patterns cite their underlying evidence and explain the inference. Seller statements remain attributed.

Use the observed unit and denominator: "Three of the six reviewed wins mention X; evidence was missing for two." Never call the intentionally balanced sample's won fraction the company's win rate.

Gaps should say what is missing, why it matters to the recipient and how it could be obtained. No compulsory owner/date matrix, enrichment execution or scoring exercise.
